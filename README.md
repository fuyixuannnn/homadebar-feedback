# HomadeBar · 家酿反馈

欢迎反馈使用问题或提出建议。提交前可以先搜索已有 Issue；同类问题可直接补充评论。

- [报告问题 / Report a problem](https://github.com/fuyixuannnn/homadebar-feedback/issues/new?template=bug.yml)
- [提出建议 / Suggest an idea](https://github.com/fuyixuannnn/homadebar-feedback/issues/new?template=idea.yml)
- [查看反馈进度 / Browse feedback](https://github.com/fuyixuannnn/homadebar-feedback/issues)
- 私密问题：[homadebar.support@gmail.com](mailto:homadebar.support@gmail.com?subject=%5BHomadeBar%5D%5B%E5%8F%8D%E9%A6%88%5D)

Issue 和评论公开可见。请不要上传密码、付款凭据或包含个人信息的截图；私密内容请通过邮件联系。我们会在 Issue 中回复和更新进度。

## 整理方式

新反馈默认标记为 `待整理`。开始处理后改为 `处理中`；需要更多信息时改为 `待补充`。处理完成后关闭 Issue，关闭说明记录结果。重复问题会链接到原 Issue。

`bug` 表示使用问题，`enhancement` 表示建议。状态标签一次保留一个；关闭状态以 GitHub 的 Open / Closed 为准。

## English

This is the public feedback space for HomadeBar. Search existing issues before opening a new one, or add a comment to an existing report. You can write in your preferred language.

Please include what happened, what you expected, and steps to reproduce when possible. Screenshots and the app/iOS version help. Posts are public; email private matters to **homadebar.support@gmail.com**.

New reports start with `待整理` (to triage), then move to `处理中` (in progress) or `待补充` (needs information). Closed issues include the outcome or a link to the original report.
